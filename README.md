# Project Documentation

## Introduction
This project focuses on healthcare information retrieval using retrieval-augmented generation (RAG) techniques.

## Getting Started
This section will guide you on how to set up the project locally.

### Prerequisites
- Python 3.x
- Required packages listed in requirements.txt

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/A-Github7702/healthcare_rag.git
   ```
2. Navigate to the project directory:
   ```bash
   cd healthcare_rag
   ```
3. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```
